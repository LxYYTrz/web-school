# ============================================================================
# 文件作用：边缘采集器的 Python 依赖清单
# 所属模块：edge/
# ============================================================================
#
# 【为什么有两个依赖】
#   ① paho-mqtt   —— MQTT 客户端。mock_collector.py 与 plc_collector.py 都要用，
#                    负责把契约报文发到 Broker、订阅下行指令。
#   ② pymodbus    —— Modbus TCP 客户端。只有 plc_collector.py（真实 PLC 采集器）
#                    需要，用来读保持寄存器（功能码 0x03）。
#                    mock_collector.py 不需要它 —— 但为现场离线安装方便，
#                    这里统一列出，免得现场切换采集器时还要再装一次。
#
# 【版本约束的写法】
#   >=2.0,<3.0 —— "至少 2.0 且不到 3.0"。
#   上界很重要：Paho 3.x 可能有不兼容改动，锁住大版本避免现场踩坑。
#
# 【离线安装（工控机无外网时）】
#   仓库里带了预下载的 wheel 包：edge/wheels/
#     paho_mqtt-2.1.0-py3-none-any.whl
#     pymodbus-*.whl
#   离线安装命令：
#     python -m pip install --no-index --find-links=edge\wheels paho-mqtt pymodbus
#   --no-index 表示不联网，直接从本地目录找包。
# ============================================================================

# MQTT 客户端（mock_collector.py / plc_collector.py 共用）
paho-mqtt>=2.0,<3.0
# 安装 Python 包 paho-mqtt；允许版本范围为大于等于 2.0 且小于 3.0。
# Modbus TCP 客户端（plc_collector.py 读 PLC 用；mock 不需要但现场切换时免装）
pymodbus>=3.10,<4.0
# 安装 Python 包 pymodbus；允许版本范围为大于等于 3.10 且小于 4.0。
