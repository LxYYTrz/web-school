# ============================================================================
# 文件作用：边缘采集器的 Python 依赖清单
# 所属模块：edge/
# ============================================================================
#
# 【为什么只有一个依赖】
#   采集器只做一件事：把数据组装成 JSON 发到 MQTT Broker。
#   MQTT 客户端用 Eclipse Paho（Python 社区事实标准）。
#   现场真实采集器会再加 OPC UA(asyncua) / Modbus(pymodbus) / S7(python-snap7)。
#
# 【版本约束的写法】
#   >=2.0,<3.0 —— "至少 2.0 且不到 3.0"。
#   上界很重要：Paho 3.x 可能有不兼容改动，锁住大版本避免现场踩坑。
#
# 【离线安装（工控机无外网时）】
#   仓库里带了预下载的 wheel 包：edge/wheels/paho_mqtt-2.1.0-py3-none-any.whl
#   离线安装命令（见 docs/工控机部署手册-U盘版.md 第 4 节）：
#     python -m pip install --no-index --find-links=edge\wheels paho-mqtt
#   --no-index 表示不联网，直接从本地目录找包。
# ============================================================================

paho-mqtt>=2.0,<3.0
